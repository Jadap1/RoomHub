# RoomHub Protocol

The RoomHub Protocol defines communication between:

- RoomHub Core
- RoomHub endpoints
- Future integrations

The protocol is designed to be:

- Hardware independent
- Versioned
- Extensible
- Human readable

## Version

Current version:

1.0

## Transport

Initial transport:

WebSocket + JSON

Future options:

- Binary streaming
- MQTT bridge
- gRPC
